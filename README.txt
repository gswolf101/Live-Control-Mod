TIKTOKCONTROL - SITE PARA GITHUB PAGES

1. Abra index.html e substitua:
   - SEU-EMAIL-AQUI pelo seu e-mail de suporte.
2. Quando criar seus produtos na Kiwify, substitua os links:
   - href="#contato" dos botões de compra pelo link de checkout correspondente.
3. Revise preço, política de atualizações e funcionalidades antes de publicar.
4. Publique os arquivos em um repositório GitHub e ative Settings > Pages.
   Selecione Deploy from a branch, branch main e pasta / (root).

O site é estático: não precisa de servidor, banco de dados ou build.
